# Version 1.2.0 — vector icons and shared design tokens

Preparation started November 20, 2026, authorized by the user. Publication is pending.

## Scope

- Reusable immutable vector definitions, standalone icons, labelled icon buttons
  and accessible icon-only buttons. Native WPF geometry caching and button behavior.
- Shared immutable spacing, typography, radius and icon scales on `ThemeTokens`.
  Scoped native icon-label spacing; explicit composition and unchanged default visuals.
- Updated skill guidance, examples and shipped API declarations.

Contracts: [icons](../icons.md), [design tokens](../design-tokens.md).
