# Version 1.1.0 — opacity and translation

Release preparation started November 20, 2026, authorized by the user. Publication
is pending. This additive minor release merges `codex/animations` into main and
promotes the reviewed animation declarations into the shipped API contract.

## Scope

- Explicit opacity/translation destinations, property masks and immutable timing.
- Lazy frame controllers and native WPF clocks; interruption, completion,
  unload/disposal and recycling retain the documented ownership contracts.
- Inherited application motion suppression plus Windows motion preferences.
- Updated portable skill, generated API reference and animation guidance.
- Corrected embedded package README, completing the planned FW-029 correction
  when the new immutable artifacts are published and verified.

See [the contract](../animation.md) and [local measurements and preserved
failures](../animation-performance-2026-11-19.md). The implementation commit
`bcdbe9fbb632ee80d3b1a171245d0fa3a4ea15fa` passed
[Validate 44620484678](https://github.com/signalnotnoise/ui-framework/actions/runs/44620484678):
196 tests, 66 Log Viewer checks, API/package/stress/lifetime checks and 32/32
performance comparisons. Release metadata changes require their own exact-commit
hosted gates. The accepted baseline remains `78c88fb901c202e3c2e49b6de300d1ce2369e00b`.
