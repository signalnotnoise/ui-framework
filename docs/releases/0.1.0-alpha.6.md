# 0.1.0-alpha.6 release record

Published October 28, 2026 from `fd725347749bcee79e29d10ac2a6de4355137be7`.
Both libraries and symbols were accepted by NuGet through Trusted Publishing.
A fresh NuGet.org installation of both exact versions passed with isolated caches;
installed DLL hashes match the hosted artifacts used for publication.

This experimental Windows/.NET 10 preview adds logical virtual-row UI Automation
discovery, safer editing/focus cleanup during recycling, scoped live contrast
colors, shared frozen normal TextBox brushes and batched theme publication.
The repository also adds offline knowledge-graph Git history correlation.

Local validation: 146/146 framework tests, 15 visual checks, 21 stress assertions,
actual-window startup/edit/disposal, API compatibility guards, package smoke
validation and 25 graph-tooling tests pass. Both formerly failing discovery tests
also pass in two additional fresh hosts after native UIA initialization was fixed.
See [test evidence](../discovery-initialization-2026-10-28.md).

Seven alternating performance pairs pass all 32 gates against unchanged baseline
`78c88fb901c202e3c2e49b6de300d1ce2369e00b`: editor mount allocation -3.72%,
themed mount allocation +0.20%, identical component work. These are workload
measurements, not general application guarantees. See [performance evidence](../theme-resource-batching-2026-10-28.md).

Manual Windows contrast switching (FW-006) and physical IME acceptance (FW-005)
remain open. User-reported Narrator and scaling acceptance do not replace these
checks. This release does not claim v1 or production readiness.

GitHub Actions is enabled; Validate and Publish NuGet are active. Publish NuGet
runs correctness, package and performance validation before its dependent NuGet
Trusted Publishing job. No baseline or threshold is relaxed for publication.

## Publication gates

Publish NuGet completed successfully: release correctness and package checks,
all 32 performance gates, then both package IDs and symbols were accepted.

Editor mount allocations improved 3.76%, update allocations improved 3.75%.
Mount time increased 0.96%, update time improved 1.85%; component work matched.
See [release comparison and raw samples](../release-evidence/2026-10-28-alpha6/release-performance/summary.md).

its 10% budget; this is recorded rather than hidden by the allocation gains.

that failed restore is retained as publication evidence.
