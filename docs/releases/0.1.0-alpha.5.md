# 0.1.0-alpha.5 release record

Prepared October 23, 2026. Publication is pending fresh hosted gates and a
verified NuGet.org installation. FW-015 tracks completion.

This experimental Windows/.NET 10 preview includes FW-002 from `f917ca6`:
themed button chrome respects native Padding and live bindings. Automatic
native Height retains the 36-DIP minimum; explicit Height allows compact
buttons and local MinHeight retains precedence. View-level Height and Padding
still apply to the outer framework frame. Framework-created buttons retain
their local 12,6,12,6 padding, which the chrome now honors.

The package-only consumer checks the compact glyph, native padding, retheming
and sizing precedence alongside native islands, style scope, editing and cleanup.
The source suite includes 13 compact-button cases, including simulated DPI,
retained rich content, focus and automation. These do not establish manual IME,
screen-reader or production application acceptance.
