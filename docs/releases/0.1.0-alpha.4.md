# SignalNotNoise UI 0.1.0 alpha 4 release

Published October 20, 2026. Status: released, indexed and verified from
NuGet.org. Completes
[FW-001](../backlog.md#fw-001-release-the-implemented-fixes).

## Scope

This release packages the native style isolation and compact input padding fixes
from `8bb20a2`. `WpfUI.Native` retains its existing overload and inherited-style
default; the new `NativeStyleScope.PreserveNative` overload is opt-in. It masks
ancestor implicit styles for common controls, not arbitrary named resources,
data templates or application behavior. The input template removes duplicate
border padding while preserving native editing, bindings and scrolling.

No consumer application code or package pin changes. Published package versions
will not be overwritten. See [native style validation](../native-style-validation.md)
for the original paired measurements and unresolved direct timing concerns.

## Local validation

The first attempt could not resolve the required .NET 10 SDK because the machine
had only a .NET 11 preview SDK installed. Installing .NET 10 into the ignored
`artifacts/release-alpha4/dotnet` directory restored the required toolchain;
`global.json` and performance budgets were not changed.

With SDK 10.0.402 and Windows Desktop runtime 10.0.13 on the same machine:

- Release build: zero warnings/errors; 106 correctness tests passed.
- All 15 visual checks and 21 stress assertions passed.
- Documentation consistency and graph tooling regression checks passed.
- Both candidate packages and symbol packages were built. A fresh package-only
  consumer with an isolated cache passed installation, transitive core
  dependency, rendering, click/state binding and rich button content checks.
- The original native overload retained one editor through 1,000 updates and
  released it exactly once. Added package checks passed for the new scope,
  scope changes, retained selection, detached cleanup and a visible compact
  query viewport with retained caret and binding feedback.

Local logs and stress results are retained in
[release evidence](../release-evidence/2026-10-20-alpha4/).
These are candidate checks before the release commit; the hosted workflow must
build and validate its own artifacts from the committed source before publishing.
The retained-update diagnostic is a single run, not a comparative speed claim.

## Hosted validation and publication

The [Publish NuGet run](https://github.com/signalnotnoise/ui-framework/actions/runs/39485610856)
passed for commit `039d3bb220e2dbddd3a11f452b0a12a673836565`. The separate
[Validate run](https://github.com/signalnotnoise/ui-framework/actions/runs/39485611332)
also passed correctness, packaging, graph and performance jobs. Trusted
Publishing pushed both packages and both symbol packages successfully.

The release performance gate used SDK 10.0.402/runtime 10.0.13, seven alternating
measured processes per side/scenario plus warmups, 1,000 rows and 50 operations.
Both sides used the same harness and application-owned editor cleanup policy.
All 32 gates passed against accepted baseline `78c88fb`; budgets were unchanged.

| Scenario | Mount time | Update time | Mount UI allocation | Update UI allocation |
| --- | ---: | ---: | ---: | ---: |
| Full list | −1.14% | −27.12% | −1.04% | −26.04% |
| Virtualized | +1.96% | −5.42% | −1.61% | −5.10% |
| Themed full list | −5.02% | −58.67% | −2.43% | −57.08% |
| Layout/editors | −1.35% | −2.36% | +0.10% | −3.78% |

Component builds and mount/unmount counts match throughout. Positive changes
are increases within budget. Improvements include earlier renderer work and
are not attributable solely to the two fixes. The standard workload does not
measure specialist islands using the new scope; FW-003 and FW-004 remain open.
[Release summary and raw runs](../release-evidence/2026-10-20-alpha4/release-performance/summary.md)
and the [independent Validate comparison](../release-evidence/2026-10-20-alpha4/validate-performance/summary.md)
retain the measurements and min/max ranges. The release report marks this
commit `releaseEligible: true`.

## Public installation verification

Both packages are indexed: [SignalNotNoise.UI](https://www.nuget.org/packages/SignalNotNoise.UI/0.1.0-alpha.4)
and [SignalNotNoise.UI.Wpf](https://www.nuget.org/packages/SignalNotNoise.UI.Wpf/0.1.0-alpha.4).
A new consumer restored the exact WPF version and transitive core package from
NuGet.org with isolated package and HTTP caches. It passed rendering, click,
state binding, rich button content, 1,000 retained native updates, both native
overloads, scope changes, compact query visibility, retained caret and cleanup.
The installed core and WPF assembly SHA-256 hashes match the corresponding
assemblies in the exact hosted artifacts used by the publishing job.

The first restore attempt preceded indexing; a second encountered the earlier
negative HTTP metadata cache. Both NU1102 attempts are retained alongside the
successful restore with an isolated HTTP cache. Neither failure was hidden by
reusing local packages. [Public installation log](../release-evidence/2026-10-20-alpha4/public-installation.log)
and [package and assembly hashes](../release-evidence/2026-10-20-alpha4/public-installation.json)
record the final check. Hosted and downloaded package ZIP hashes differ after
NuGet signing; the assembly payload hashes match. FW-001 is Done.

## Preview limitations

Fresh
visible-window IME and screen-reader acceptance has not been performed for this
release; the earlier alpha.3 campaign does not establish acceptance for the new
scope or for a third-party editor. This remains an experimental preview.
