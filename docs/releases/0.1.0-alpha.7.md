# 0.1.0-alpha.7 release record

Published November 13, 2026 from `c5d639bcff707ff1a75b23f2a60135d6be6cb7b2`.
Both libraries and symbols were accepted through NuGet Trusted Publishing;
both are publicly indexed and fresh installation verification passed.

This preview packages the keyed virtual-row improvements since alpha.6 and
retains the existing public API. The repository additionally includes native/
WebView2 ownership acceptance, user-confirmed historical IME/contrast acceptance,
and the agent skill with native before/after media. The skill is distributed
from the repository, not installed by the NuGet library packages.

## Release requirements

- Local full Release validation and isolated package consumer checks.
- Seven alternating local performance pairs using the same harness and SDK for
  both sides, with full-list, virtualized, themed and editor workloads. Preserve
  raw runs, failures and the accepted baseline/budgets without modification.
- Successful full hosted performance comparison for the exact candidate commit,
  plus correctness, graph and package gates. Local timing is diagnostic; an exact
  candidate hosted pass is the performance release gate per the October 29 decision.
- Trusted Publishing of both libraries and symbols, followed by a fresh
  NuGet.org-only restore/run with isolated caches and assembly hash comparison.

No production/v1 readiness claim is made. Existing manual acceptance remains
scoped to its recorded environments; provider stall policy and arbitrary native
integration remain application responsibilities.

## Public installation

A new consumer restored both exact alpha.7 packages using NuGet.org only, with
empty package and HTTP caches. Rendering, click/state updates, retained native
interop, style scope, selection, binding, compact controls and cleanup passed.
Both installed DLL SHA-256 hashes match the hosted packages used for publication.
NuGet signing can change archive hashes; the assembly payloads match.
See the [installation log](../release-evidence/2026-11-13-alpha7/public-installation.log)
and [hash verification](../release-evidence/2026-11-13-alpha7/public-installation.json).
The initial restore before indexing returned NU1102 and only alpha.6; its
[failed log](../release-evidence/2026-11-13-alpha7/public-installation-attempt-1.log)
is retained. No publishing retry was needed.

Install with `dotnet add package SignalNotNoise.UI.Wpf --version 0.1.0-alpha.7`.
The matching core package is restored automatically. The agent skill and GIF
remain available from the source repository; NuGet installs the runtime libraries.
