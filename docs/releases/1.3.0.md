## What changed

FW-040 adds independent Button/IconButton hints: explicit text overrides native
style hints, null restores automatic behavior, and empty text suppresses them.
Accessible names and retained control identity remain independent. Core stores
only text; one small WPF helper owns property precedence. Native WPF retains
presentation, keyboard/disabled policy and timing without new policy constants.

FW-041 clarifies outer-frame versus native icon-button sizing with a compiled
compact toolbar recipe, shared tokens, application-owned target sizing and
contrast/DPI coverage. Native sizing semantics are unchanged. Each new C# file
declares one type, with no broad refactor or extra runtime abstraction.
