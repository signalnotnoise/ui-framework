## SkillIconToolbarExample

WPF-only compact toolbar: frame sizes are separate from native sizes. ApplyTheme before attaching the dedicated host; the Loaded handoff clears renderer-local padding so this scoped style owns it. Reapply after theme/contrast changes with the current system contrast flag so the quiet surface stays readable. Keep the framework template and Quiet appearance for feedback; arbitrary consumer templates retain their own responsibility.

Source: `tests/UI Framework.Checks/SkillExamples/SkillIconToolbarExample.cs`

```csharp
using System.Windows;
using System.Windows.Controls;
using UI_Framework;
using UI_Framework.Wpf;
using static UI_Framework.UI;

public sealed class SkillIconToolbarExample
{
    // Application-owned hit target, independent of the icon's display size.
    public const double TargetSize = 32;
    private static readonly VectorIcon search = new("M10,3 A7,7 0 1 0 10,17 A7,7 0 1 0 10,3 M15,15 L21,21", strokeWidth: 2);
    private ThemeTokens theme;
    private readonly Action searchAction;

    public SkillIconToolbarExample(ThemeTokens theme, Action searchAction)
    {
        this.theme = theme;
        this.searchAction = searchAction;
    }

    public View Body() => HStack(CreateAction("Search", true), CreateAction("Unavailable search", false))
        .Spacing(theme.Spacing.Small).Padding(theme.Spacing.Small)
        .Background(theme.Canvas).Foreground(theme.Ink);

    private View CreateAction(string name, bool enabled) => IconButton(search, name, searchAction)
        .FontSize(theme.Icons.Small).Width(TargetSize).Height(TargetSize)
        .ButtonStyle(ButtonStyleKind.Quiet).IsEnabled(enabled);

    // The application's theme owner calls this with SystemParameters.HighContrast,
    // initially and again when its theme/contrast settings change.
    public void ApplyTheme(ViewHost toolbar, ThemeTokens value, bool highContrast)
    {
        theme = highContrast
            ? value with { Canvas = SystemColors.WindowColor.ToString(), Ink = SystemColors.WindowTextColor.ToString() }
            : value;
        ThemeStyles.Apply(toolbar, theme);
        var style = new Style(typeof(Button), (Style)toolbar.Resources[typeof(Button)]);
        style.Setters.Add(new Setter(FrameworkElement.WidthProperty, TargetSize));
        style.Setters.Add(new Setter(FrameworkElement.HeightProperty, TargetSize));
        style.Setters.Add(new Setter(Control.PaddingProperty, new Thickness(0)));
        // Only this dedicated toolbar opts into style-owned padding. Node sets
        // local padding; a Setter alone cannot override that value.
        style.Setters.Add(new EventSetter(FrameworkElement.LoadedEvent,
            new RoutedEventHandler(UseToolbarPadding)));
        toolbar.Resources[typeof(Button)] = style;
        toolbar.Refresh();
    }

    private static void UseToolbarPadding(object sender, RoutedEventArgs args) =>
        ((Button)sender).ClearValue(Control.PaddingProperty);
}
```

## SkillLayoutExample

Use Dock/Flex for finite space; stacks remain content-sized. A stack can itself be a weighted child of a flex container. Keep splitter state on the component.

Source: `tests/UI Framework.Checks/SkillExamples/SkillLayoutExample.cs`

```csharp
using UI_Framework;
using static UI_Framework.UI;

public sealed class SkillLayoutExample : Component
{
    private readonly State<double> sidebarWidth = new(240);

    public override View Body() => Dock(
        SplitPane(VStack(Text("Sources"), Text("Local logs")),
            FlexColumn(Text("Entries").Height(24),
                FlexRow(Text("Message").Flex(2), Text("Severity"))),
            sidebarWidth, SplitAxis.Horizontal, minimumFirst: 180, minimumSecond: 320),
        top: HStack(Text("Log viewer"), Text("Ready")).Height(32),
        bottom: Text("Connected").Height(24));
}
```

## SkillStateExample

Do not allocate State or Computed in Body. Retained fields survive builds; the constructor creates the derived value once.

Source: `tests/UI Framework.Checks/SkillExamples/SkillStateExample.cs`

```csharp
using UI_Framework;
using static UI_Framework.UI;

public sealed class SkillStateExample : Component
{
    private readonly State<string> filter = new("");
    private readonly Computed<string> normalized;

    public SkillStateExample() => normalized = new(() => filter.Value.Trim());

    public void SetFilter(string value) => filter.Value = value;

    public override View Body() => VStack(
        TextField(filter).AccessibilityLabel("Filter"),
        Text(normalized.Value));
}
```

## SkillRowsExample

Do not use positions or fresh random keys. Key each row by a unique domain ID; ReplaceAll can reorder these identities. Removed rows lose local state. Offscreen retention is governed by the virtualization guide.

Source: `tests/UI Framework.Checks/SkillExamples/SkillRowsExample.cs`

```csharp
using UI_Framework;
using static UI_Framework.UI;

public sealed class SkillRowsExample : Component
{
    private readonly StateList<string> items = new(["log-a", "log-b"]);

    public void ReplaceRows(params string[] ids) => items.ReplaceAll(ids);

    public override View Body() => VirtualList(
        items.Select(id => Component<SkillRowExample>(row => row.EntryId = id).Id(id)),
        height: 480);
}
```
